How the exam works

  • Each problem has three actions: Run Sample Tests (checks your code against the visible examples only — unlimited attempts, never scored), Submit Solution (grades that one problem against every test case, including hidden ones — you can resubmit and your best score counts), and Submit Assessment (locks in your best score on every problem and ends the exam for good — only do this once you're completely done).
  • Your code is saved automatically as you type. If your browser or tab reloads, you can resume from exactly where you left off — you will not lose work.
  • The timer is set by our server, not your computer's clock, and cannot be paused once it starts — including if you close the tab.

Rules — read carefully

  • Do not exit fullscreen. If you do: it's logged every time. After repeated exits, your session is automatically locked and whatever you've done so far is submitted for you — you cannot undo this or get the exam back.
  • Do not copy or paste anything, in or out of the code editor. If you try: paste is blocked outright (nothing gets pasted), and the attempt is logged for review.
  • Do not switch tabs, minimize the window, or click away from the exam. If you do: it's detected and logged as a tab switch / focus loss for academic integrity review, even briefly.
  • Do not use browser developer tools or keyboard shortcuts like Ctrl+C / Ctrl+V / F12. If you try: the shortcut is blocked and the attempt is logged.
